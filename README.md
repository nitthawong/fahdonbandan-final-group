# Chat AI พร้อม Portfolio ของกลุ่มฟ้าดลบันดาล

โปรเจกต์เว็บแอปพลิเคชัน Portfolio ที่ให้ผู้เยี่ยมชมสามารถพูดคุยกับ AI เพื่อสอบถามเรื่องราว ผลงาน และทักษะของกลุ่มและสมาชิกแต่ละคนได้

## สมาชิกในกลุ่ม
1. ภุพิง (พชรพล กมลเลิศ) - AI Integration & CI/CD Pipeline
2. รัน (นิษฐา วงค์ยะลา) - Backend API
3. แฮม (อาทิตยา รวยทรัพย์) - Frontend Developer & Chat UI

## การติดตั้งและการรันโปรเจกต์
1. Clone repository นี้ลงเครื่อง
2. เข้าไปที่โฟลเดอร์ frontend และ backend เพื่อติดตั้งแพ็กเกจด้วยคำสั่ง `npm install`
3. ตั้งค่าไฟล์ `.env` ตามไฟล์ `.env.example`
